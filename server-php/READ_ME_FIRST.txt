PLAYFOOD Archipelago | cPanel upload | 29 November 2026

1. Choose a website
Use a dedicated HTTPS domain or subdomain. In cPanel > Domains, find its
document root (often public_html). Back up any existing website and private
PLAYFOOD folder first. Ask your host for Apache, PHP 8.2 or later, PDO SQLite
with SQLite 3.35 or later, and permission for PHP to create a private folder
above the public website. Apache must allow Options, FileInfo and AuthConfig
overrides, with mod_headers and mod_setenvif enabled.

2. Upload the game
Unzip the package on your computer and open PLAYFOOD_Upload. In cPanel File
Manager, enable Settings > Show Hidden Files. Place everything INSIDE
UPLOAD_CONTENTS directly in the domain's document root. You may zip those
contents locally, upload that ZIP, extract it in the root and delete the ZIP
there. Check that index.html and setup.php are directly in the root and that
.htaccess is present in the root, api/ and api/lib/. Keep this guide locally.
If you already have a custom .htaccess, ask your host to merge the rules and
preserve its PHP handler. The game is already built.

3. Set up this school
Open https://YOUR_DOMAIN/setup.php. The first visit creates a private key on
your hosting account. The page shows the name of your playfood-private-...
folder. In cPanel File Manager, go above the website's public folder and open
the named folder. View installation-key.txt and copy its single line.
Return to the setup page, paste the key, enter the teacher's email, choose a
new password (12 to 72 bytes) and select the school's time zone. Select the
statistics checkbox only if your institution approves collection. For a test
with fictional data, enable it to check the panel. Select Install PLAYFOOD.
After success, delete setup.php from the website. Sign in to /panel/ with the
teacher email and password you chose. Setup consumes the key.

The private folder holds settings, the database and phygital-codes.json.
The latter holds five fresh Activity Codes for this installation. View it
privately in File Manager and give the appropriate code to each teacher.
See D5 section 8 for managing activities. Keep this entire folder private.

4. Check the result
Open https://YOUR_DOMAIN/api/index.php?route=health. Check that db is true
and tracking matches your choice. Confirm /setup.php now returns 404. Open
the game at https://YOUR_DOMAIN/ in a fresh browser session. Play a mission
and open a source. With statistics enabled, sign in at /panel/, check the
new activity, refresh the panel and choose Export CSV. Open the downloaded
file and check the event rows. At the Lighthouse postbox, try a newly issued
Activity Code with a test player and confirm the points.

For an existing installation, preserve its private folder, keep old hashed
assets alongside new ones, merge hosting rules, delete any uploaded setup.php
and clear the hosting cache. For hosting checks, updates and backups see
Deliverable 5, section 6, Route A, and section 10. In this D6 edition the
setup key and redeemable codes are generated by each new installation.
