Who Is Playing

Profiles are random IDs stored in the browser, not verified counts of children. Children sharing a browser may share one profile; clearing browser data or switching browsers may create another. If browser storage is unavailable, the ID lasts only for the current page load.

Game Profiles counts each profile once when a game start, finish or quit is recorded in the selected period and language. Opening a game includes its introduction and does not prove that the child began answering. Opening or refreshing the landing page alone does not count. A Play Code restores game progress, not this ID: using the same code on another browser does not link the profiles.

The language bars count game profiles once per recorded game language. A profile that opens games in several languages can appear in several bars.

Languages

Game Participation

How far game profiles get within the selected period and language. Each step counts profiles that reached at least that point. Percentages use the profiles that opened a game as their denominator.

Island completion and 12/12 require confirmed passes in the selected period and language, not lifetime progress. Older outcomes without a recorded pass/fail remain unknown and cannot confirm completion.

Per Game

All twelve games, with one table per island, including any island or game that nobody has touched yet.

Started counts recorded round starts; Rounds Ended counts recorded round finishes. Both follow the selected period and language and include replays. Matched rate counts only identified starts and their matching finishes within that selection, shown as finishes/starts. A finish means the round ended, not necessarily that it was passed. Unpaired finishes include older results and results whose start is missing or outside the filter. “—” means no identified starts are available.

Elapsed times include instructions, pauses, hidden tabs and inactivity. The new time split averages only measured rounds, including quits. Play = available gameplay with recent input; Guidance = instructional/help/decision panels displayed, not proof of reading; Pause = pause/exit menu; Away = hidden or unfocused page (including external source tabs); Possible idle = time beyond 5 minutes without input during play or guidance; Other = loading, transitions and results. Categories do not overlap. Older rounds have no split.

Quit At is average recorded objective progress on exit, not accuracy or time played. Missing progress is excluded; 100% does not imply a pass. Older versions recorded a fixed 0%, so periods containing those records are not reliable for this metric.

Scroll each table sideways to see all columns. With a keyboard, focus the table and use the left/right arrow keys.

Star Distribution

How many rounds ended with 0, 1, 2 or 3 stars, per game, grouped by island. Rounds without recorded stars are counted separately. Every game is listed, including those with no recorded finishes.

Per ended attempt, not per learner or best result. Unrecorded stars are excluded from the average; zero stars are included. Stars do not determine pass/fail.

Activity Codes

Offline activities whose activity code was typed into the game in the lighthouse postbox, for the selected period and game language. These are separate from the Play Code used to restore game progress. Only the activity name from your activity list is recorded.

Actions

Export recorded events as CSV or this summary as an A4 PDF. CSV contains event rows, not one row per child. Rows marked filtered follow the selected period and language. A one-language CSV also includes visit_context rows for the selected visits: their start, end and character-choice events may be outside that period or language. Use only filtered rows for activity counts within your selection.
