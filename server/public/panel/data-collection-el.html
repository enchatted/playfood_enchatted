PLAYFOOD — συλλογή δεδομένων

Σκοπός και αναγνωριστικά

Όταν είναι ενεργά τα στατιστικά, το PLAYFOOD καταγράφει δραστηριότητα παιχνιδιού για τους δείκτες του έργου: επισκέψεις, καταγεγραμμένα προφίλ browser, προσπάθειες, ολοκληρώσεις και χρόνους. Το τυχαίο learner_id αποθηκεύεται στο local storage του browser με κλειδί playfood-learner. Αναγνωρίζει προφίλ browser, όχι επιβεβαιωμένα ένα παιδί. Κοινός browser μπορεί να σημαίνει κοινό ID· διαγραφή δεδομένων ή άλλος browser/ιστότοπος μπορεί να δημιουργήσει άλλο. Χωρίς διαθέσιμο storage ισχύει μόνο όσο μένει φορτωμένη η σελίδα. Είναι σταθερό ψευδωνυμικό αναγνωριστικό, όχι εγγύηση πλήρους ανωνυμίας. Νέο τυχαίο session_id αναγνωρίζει κάθε φόρτωση/επίσκεψη και τυχαίο attempt_id κάθε προσπάθεια παιχνιδιού.

Πεδία που αποθηκεύονται

Κάθε γεγονός έχει ts (χρόνος παραλαβής στον server, σε χιλιοστά του δευτερολέπτου από το Unix epoch), learner_id, session_id, type, island, game, score, stars, duration_s, progress, language και returning. Στις προσπάθειες μπορεί να υπάρχουν attempt_id και passed (επιτυχία/αποτυχία ολοκληρωμένου γύρου). Όσα πεδία δεν εφαρμόζονται μένουν κενά. Οι τύποι είναι session_start, hero_chosen, island_enter, game_start, game_finish, game_abandon, session_end και phygital_redeem. Στο hero_chosen, η στήλη game περιέχει το προκαθορισμένο ID ήρωα, όχι όνομα παιχνιδιού. Στο phygital_redeem (έγινε δεκτός κωδικός για δραστηριότητα εκτός οθόνης), η στήλη game περιέχει το ID της δραστηριότητας από τη λίστα του σχολείου· ο κωδικός που πληκτρολογήθηκε δεν αποθηκεύεται. Το progress είναι η πρόοδος στόχου κατά την έξοδο, όχι μαθησιακή βαθμολογία. Το language είναι γλώσσα παιχνιδιού, όχι χώρα· το returning δηλώνει ότι βρέθηκε ήδη ID στατιστικών στον browser.

Μετρήσεις χρόνου

Νέοι γύροι που ολοκληρώνονται ή εγκαταλείπονται μπορεί να έχουν timing_version=1 και έξι αμοιβαία αποκλειόμενα σύνολα δευτερολέπτων: active_s (διαθέσιμο παιχνίδι με πρόσφατο χειρισμό), learning_s (εμφάνιση οδηγιών/βοήθειας/καρτών αποφάσεων), paused_s (παύση ή μενού εξόδου), hidden_s (κρυμμένη σελίδα ή χωρίς εστίαση), idle_s (χρόνος μετά από πέντε λεπτά χωρίς χειρισμό στο παιχνίδι ή στις οδηγίες), other_s (φόρτωση, μεταβάσεις και αποτελέσματα). Ο χρόνος οδηγιών δεν αποδεικνύει ανάγνωση και ο ενεργός χρόνος δεν αποδεικνύει μάθηση. Το duration_s είναι συνολικός χρόνος γύρου ή επίσκεψης, μαζί με παύσεις και κρυμμένη σελίδα. Αν λείπει τελικό γεγονός, ο χρόνος μένει άγνωστος· παλιές εγγραφές μπορεί να μην έχουν ανάλυση. Δεν αποθηκεύονται στη βάση στατιστικών μεμονωμένα πλήκτρα, κινήσεις δείκτη ή απαντήσεις.

Τι δεν περιέχει η βάση γεγονότων

Η λίστα επιτρεπόμενων πεδίων αποκλείει ονόματα, email, διευθύνσεις IP, user-agent και ελεύθερο κείμενο. Ο server λαμβάνει αναγκαστικά διευθύνσεις δικτύου και τις χρησιμοποιεί προσωρινά στη μνήμη για όρια αιτημάτων· αυτό διαφέρει από την αποθήκευσή τους σε γεγονότα. Τα email προσωπικού και τα hashes κωδικών του panel φυλάσσονται χωριστά στο users.txt, με προσωρινές συνεδρίες σύνδεσης στη μνήμη του server. Ο browser κρατά χωριστά την πρόοδο του παιχνιδιού. Το Play Code επαναφέρει πρόοδο, χωρίς να συνδέει τα ID στατιστικών διαφορετικών browsers.

Αποθήκευση και πρόσβαση

Το τοπικό πακέτο ελέγχου αποθηκεύει τα γεγονότα στο server/playfood.db (SQLite), στον υπολογιστή που τρέχει τον server. Το συνδεδεμένο προσωπικό του panel βλέπει σύνολα, εξάγει γεγονότα σε CSV και μπορεί να λάβει αντίγραφο βάσης από το API που απαιτεί σύνδεση. Το CSV κρατά το ts και προσθέτει timestamp_utc σε μορφή ISO 8601 UTC. Σε φιλοξενούμενη εγκατάσταση η αποθήκευση γίνεται στον server της: ο υπεύθυνος πρέπει να επιβεβαιώσει πάροχο, χώρα, πρόσβαση και τυχόν αρχεία καταγραφής proxy/server πριν από τη χρήση. Το παρόν δεν πιστοποιεί ότι η δημοσιευμένη υπηρεσία έχει ελεγμένη φιλοξενία στην ΕΕ.

Προεπιλογές, διατήρηση και απενεργοποίηση

Η προεπιλογή είναι PANEL_ENABLED=no. Το ρυθμισμένο πακέτο ελέγχου μπορεί να το ενεργοποιεί ρητά. Το RETENTION_MONTHS έχει προεπιλογή 24· εγγραφές παλιότερες από το ρυθμισμένο όριο διαγράφονται στην εκκίνηση και κάθε 24 ώρες λειτουργίας του server. CSV, PDF και αντίγραφα που έχουν ήδη εξαχθεί είναι χωριστά αρχεία και δεν διαγράφονται αυτόματα. Βάλε PANEL_ENABLED=no στο server/playfood.config.txt και αποθήκευσε: μέσα σε 30 δευτερόλεπτα ο server ξαναδιαβάζει τη ρύθμιση, απορρίπτει νέα γεγονότα και κλείνει την πρόσβαση δεδομένων του panel. Ανανέωσε και τη σελίδα παιχνιδιού ώστε ο browser να σταματήσει να στέλνει. Η απενεργοποίηση δεν διαγράφει παλιές εγγραφές ή τα ID/πρόοδο του browser. Ο υπεύθυνος εγκατάστασης διαχειρίζεται τα υπάρχοντα αντίγραφα και τα αιτήματα διατήρησης.
